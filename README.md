# Slimu Neet — Homepage

Homepage cá nhân của **Slimu Neet** — freelancer tại thành phố Hồ Chí Minh.

## Chạy dự án

```bash
bun install
bun run dev      # http://localhost:3000
bun run build    # build production
bun run start    # chạy bản production
```

## Stack

- [Next.js](https://nextjs.org/) (Pages Router) — React framework
- [Chakra UI](https://chakra-ui.com/) — UI component library
- [Three.js](https://threejs.org/) — 3D (voxel dog)
- [Framer Motion](https://www.framer.com/motion/) — animation

## Cấu trúc

```
├── pages        # Trang (/, /404)
├── components   # React components
├── lib          # theme, 3D model loader
└── public       # Ảnh tĩnh + 3D model (dog.glb)
```
